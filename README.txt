# Cultural Data Analysis with SQL

This project demonstrates SQL-based analysis on a cultural heritage dataset.

## Description

The dataset includes cultural heritage items and their creators. The goal is to organize, query and analyze the data using SQL.

## Skills demonstrated

- Data querying with SQL
- Filtering data with WHERE
- Aggregation with COUNT and GROUP BY
- Joining tables
- Basic cultural data analysis

## Tools

- MySQL
- phpMyAdmin
- CSV
- SQL
